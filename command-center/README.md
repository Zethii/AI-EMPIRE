# Command Center

The command center is the planned entry point for tasks, delegation, approvals, status, and final synthesis. No runtime exists yet.

Planned modules:
- executive-agent: interpret user requests and produce plans
- task-router: choose agents and model/provider based on task needs
- task-manager: track task state, deadlines, dependencies, results
- approval-system: pause for explicit approval before sensitive actions

See `docs/ARCHITECTURE.md` for the initial task lifecycle.
